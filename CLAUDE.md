## Handoffs

Work that belongs in another repo is written down there, not done from here:
`<target-repo>/_handoffs/YYYY-MM-DD-<topic>.md` with frontmatter
`status: open|claimed|done`, `from_repo`, `from_session`, `created`, `claimed_by_session`;
body = context, the job in one sentence, decisions for Brian (one at a time, each with a
recommendation), what must keep working, how to verify; and it ends with a fenced
**paste-in prompt** ("Read this file first, then CLAUDE.md…"). A session that picks a
handoff up flips it to `claimed` in its first commit and to `done` at closeout. Session
Manager lists open handoffs and can launch them.

## Parallel work

One working tree, one session. A second concurrent session in this repo works in a
worktree: `git worktree add ~/<repo>-wt/<topic> -b <branch>` and merges back
fast-forward only. Session Manager shows a collision badge when two live sessions share
a working tree.

## End of session

Run the `closeout` skill: it writes the one-line summary, commits and pushes, adds any new
gotcha to this file's Never list, writes handoffs for work that belongs elsewhere, flips
consumed handoffs to `done`, writes the Notion manual log when the diff cannot carry the
reasoning, then ends the session.
